# 视频素材全流程规范（转字幕 → 修正翻译 → 进视频 tab）

> 目的：把一条视频做成「视频 tab」里能点读、能逐词跟读、能看译文的学习素材。
> 本文件是操作规范；新会话照此执行即可。工具细节见各仓库自己的 README。
>
> **同一份规范的速查版也写在 skill `dango-subtitle-converter` 里**（AI 用到转写工具时会自动加载，
> 不需要用户提醒）。**改规则时两处一起改。**

## 0. 分工与路径

| 角色 | 位置 |
|---|---|
| 转写工具（产素材） | `E:\dango-subtitle-converter\transcribe` |
| 逐词对齐（独立脚本，可选） | 同上 `tools\align_words.py`，跑在 `E:\align-venv` |
| 学习 App（消费素材） | `E:\日语50音`，字幕库默认 `subs\`（`config.json` 的 `subtitleDir`） |
| 点读语音缓存 | `E:\日语50音\assets\audio\tts\`（Edge Nanami，串行合成） |
| 词义缓存 | `E:\日语50音\cache\glosses.json`（键＝「句+词」，跨浏览器/跨 origin 共用） |
| 运行日志 | `E:\日语50音\logs\app.jsonl`（白名单事件） |

## 1. 转录：出学习字幕 + 日文字幕

```powershell
transcribe "<链接或本地文件>" -l ja --no-subs --fine --study -o "E:\日语50音\subs"
```

- `-l ja` 日语；`--no-subs` 不用平台字幕（要词级时间）；`--fine` 词级时间戳；`--study` 出学习字幕
- 平台有**人工日文字幕**时可去掉 `--no-subs`，但自带字幕一般没有词时间，点读/光斑会退化
- 歌/音乐：VAD 会把唱段滤掉 → 工具自动回退无 VAD 模式，慢但可用
- 产物：`<名>.srt`（日文）、`<名>.study.json`（学习字幕）

## 2. 有已知歌词时：先做句级对齐（推荐）

歌词文件**按词加空格**（最重要的一条，见「硬规则 1」）：

```
だんご だんご だんご だんご だんご だんご
大家族
やんちゃな 焼きだんご
おすまし ごまだんご 四つ子 串だんご
```

```powershell
transcribe --align-lyrics "<名>.study.json" --lyrics "歌词.txt" -l ja
# -> <名>.study.aligned.srt + <名>.study.aligned.study.json
```

结束会报「N 行没匹配上，已按前后时间插值，请核对: x, y」——**必须逐行核对这几个编号**。

## 3. 逐词强制对齐（要逐词精度就做）

```powershell
E:\align-venv\Scripts\python.exe E:\dango-subtitle-converter\transcribe\tools\align_words.py `
  --study "<名>.study.aligned.study.json" --media "<视频或音频>" --device cuda `
  --out "<名>.words.study.json"
```

- 环境 `E:\align-venv`（torch + transformers，全装在 E 盘）；`HF_HOME=E:\hf-home`
- **只细化词/字的时间，句子的起止时间不动**（动了译文就对不上）
- 结束会报「没对齐上的词占比」和「与旧词时间的偏差」；占比高说明歌词与音频差得多
- 词划分**按歌词里的空格**——歌词怎么写，App 里按钮就怎么切

## 4. 修正 + 翻译（由 AI 做，工具只负责导出/回填）

```powershell
transcribe --dump-lines "<名>.srt"          # ① 导出原文行 -> <名>.srt.lines.txt
# ② 通篇读完再逐行翻：术语跨行统一、断句跟意群，写成 <名>.zh.txt（每行一句，行数必须一致）
transcribe --retext "<名>.srt" --text "<名>.zh.txt" -l zh    # ③ 回填 -> <名>.zh.srt
```

- **必须通篇给上下文**：逐行孤立地翻会得到「不贴合语境」的译文（实际踩过这个坑）
- 行数与原 srt 不一致时 CLI 直接报错（防错位）
- **【IMPORTANT】拿不准的行必须抽帧核对，不许猜、不许留空**：听不出 / 听错 / 词被切到邻行 / 疑似幻觉（如一串「あああ」）时，
  `transcribe --frames "<名>.srt" --video "<视频>" --at "行号,行号"` 抽帧 → 用 read 看 `<名>.shots\*.jpg`：
  原片/压制版画面底部通常有中文字幕，可作**旁证**（别照抄，仍要自己产日语+中文）。
  **批量派子 agent 改稿时，这条必须写进它的指令里**——它是判定质量的关键，漏了 agent 只能靠上下文猜。
  画面也看不出来 → 标「需人工确认」，不许编。

## 5. 放进 App（三件套同名）

| 文件 | 作用 | 可否缺 |
|---|---|---|
| `<名>.mp4` | 视频 | 可缺（缺了标「无视频」，只出字幕） |
| `<名>.study.json` | 学习字幕：词划分 + 逐词/逐字时间 | **不可缺**（缺了没有点读/逐词跟随） |
| `<名>.zh.srt` | 中文译文 | 可缺；**时间轴必须与 study.json 一致**（不一致 App 拒绝加载） |

放进字幕库后刷新 App → 「视频」页「已处理」列表里出现 → 点开即用（不用再手动选文件）。

## 6. 首次打开时的自动准备（App 侧自动，操作者不用管）

- **点读语音**：把该视频用到的所有词**串行**合成并就近存到 `assets/audio/tts/`（每词 1~3 秒，每个视频只做一次）。
  **必须串行**：并发会触发微软限流，实测并发 2~3 时每词要 45~90 秒且频繁超时。
- **词义**：先查服务端缓存 `cache/glosses.json`；缺的**带上每个词所在的那句原文**批量问 DeepSeek，
  结果按「句+词」落缓存，之后换浏览器、换 origin 都直接命中。
- **罗马音**：本地 kuroshiro 转换，不联网。

## 硬规则（都是踩过的坑）

1. **歌词/字幕按词加空格**。它决定按钮词划分、罗马音、词义、光斑粒度。不加空格时通用分词器会把
   「だんご」切成 `だ|ん|ご`（罗马音变成 `da n go`、词义只能给碎片义）。加空格**不影响**歌词对齐的行匹配
   （比对时会丢掉空格）。
2. **翻译必须通篇给上下文**，术语跨行一致，断句跟意群，不要跟着识别碎片断（否则出「调皮的烤团子 呀」）。
3. **词义必须带句子**；服务端回填只按**词原文**匹配、不按位置（模型会错位，曾出现 `まし→赏月`）。
4. **逐词对齐脚本不属于常规转换路径**，只在备素材时手动跑，不要接进默认流程。
5. **素材同名**：视频 / 学习字幕 / 译文必须同基名，否则 App 配不上。
6. **不许改 study.json 的句子时间**：译文按它对齐。
7. **发音一律 Edge Nanami**：App 侧只走 `UI.speak`，不要自己 `new Audio` 或直接调 `speechSynthesis`。
8. **只用 `http://localhost:3000`** 打开 App（`127.0.0.1` 会自动 301 跳回 localhost）；学习进度存在浏览器
   localStorage，换浏览器 / 换 origin 看不到（词义和语音不受影响，它们在服务端 / 本地文件里）。
9. **【IMPORTANT】拿不准的行抽帧核对，不许猜、不许留空**（详见第 4 节）：改稿（自己改或派子 agent 改）
   遇到听不出/听错/被切碎/疑似幻觉的行，先 `--frames` 抽帧看画面里的字幕再定稿。**派 agent 时必须把这条写进指令。**

## 质量闸门（交付前逐条打勾）

- [ ] `study.json` 与 `zh.srt`：行数一致、时间轴一致（App 会校验，不一致直接报错）
- [ ] 词划分是人看的词，不是 `だ|ん|ご` 这类碎片
- [ ] 抽查 3~5 个词：悬停词义是否贴合它所在的那句
- [ ] 抽查 3~5 句译文：连贯、术语一致、无半截句
- [ ] 视频页：句子数/词数正常、光斑逐词跟、点词有声音、进度条能拖
- [ ] `logs/app.jsonl` 无新的 `gloss_failed` / `tts_failed` / `library_*_failed`
- [ ] 歌词对齐报的「没匹配上的行」已人工核对过

## 失败排查

| 现象 | 看哪里 |
|---|---|
| 工具报错 / 下载失败 / 模型问题 | `E:\dango-subtitle-converter\transcribe\docs\troubleshooting.md` |
| App 字幕读不出、语音没备上 | 页面提示 + `E:\日语50音\logs\app.jsonl` |
| 词义不贴合 / 不对 | 是否漏了句子语境；`gloss_shape` 事件＝模型返回条数与输入不符 |
| 逐词对齐跑不起来 | 需要 `E:\align-venv`（缺 torch/transformers 会直接报错） |

## 实例（団子大家族，本次实际跑过一遍）

```powershell
# 1 转录
transcribe "https://www.bilibili.com/video/BV1yv6XYcEjM/" -l ja --no-subs --fine --study -o "E:\字幕库"

# 2 歌词（按词加空格）做句级对齐
transcribe --align-lyrics "E:\字幕库\…だんご大家族….study.json" --lyrics "E:\字幕库\団子大家族.lyrics.v2.txt" -l ja

# 3 逐词对齐
E:\align-venv\Scripts\python.exe E:\dango-subtitle-converter\transcribe\tools\align_words.py `
  --study "E:\字幕库\…study.aligned.study.json" --media "E:\字幕库\団子大家族.mp4" --device cuda `
  --out "E:\字幕库\団子大家族.words.v2.study.json"

# 4 回填译文（译文行文件：每行一句，通篇语境翻的）
transcribe --retext "E:\字幕库\…study.aligned.srt" --text "E:\字幕库\団子大家族.zh.lines.v2.txt" -l zh

# 5 三件套同名放进字幕库
#   E:\字幕库\団子大家族.mp4 → E:\日语50音\subs\団子大家族.mp4
#   団子大家族.words.v2.study.json → subs\団子大家族.study.json
#   …study.aligned.zh.srt → subs\団子大家族.zh.srt
```

结果：31 句 / 139 词；逐词光斑、点读音频本地化、悬停词义带语境、译文通篇统一。
