# C 盘清理选择器设计

## 目标

提供一个离线单文件 HTML，让用户逐项判断 C 盘清理候选，尤其能看懂 Windows SDK、ASCOM、Camera Raw、Hugging Face 模型、Playwright 等不直观项目的用途和风险，并导出 JSON 供后续生成清理方案。

## 约束

- 不读取 C 盘、不执行删除、不调用网络。
- 不默认勾选任何需要用户判断的项目。
- “无脑清理”只包含可重建的普通临时/下载缓存，并仍提示关闭相关软件。
- 不把聊天记录、浏览器用户资料、系统分页文件、Installer/Package Cache 放入可直接清理项。

## 界面与数据流

页面顶部显示检查摘要和安全边界；主体按“可直接清理 / 需要你判断 / 建议保留”分组。
每项卡片包含复选框、名称、空间、标签、用途、影响、恢复方式和路径；点击“查看详情”展开说明。底部固定操作栏显示已选数量和估算空间，支持全选本组、清空选择、导出 JSON、复制 JSON。

JSON 包含 schema 版本、生成时间、磁盘摘要、每项的 selected 状态与完整元数据，便于后续按 ID 生成安全操作步骤。

## 验证

- 通过 HTML 语法/脚本静态检查。
- 检查默认无用户判断项被选中。
- 检查勾选、分组全选、清空、导出、复制和 JSON 可解析。
- 使用本地浏览器验证桌面和窄屏布局，且不产生网络请求。
